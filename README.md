# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a basic program that calculates the simple interest and total amount using the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal Amount
- R = Rate of Interest
- T = Time Period

Total Amount = Principal Amount + Simple Interest

## Features

- Accepts principal amount from the user
- Accepts rate of interest
- Accepts time period
- Calculates simple interest
- Calculates total amount
- Displays the results clearly

## Example

Input:

Principal Amount = 10000  
Rate of Interest = 5%  
Time = 2 years

Output:

Simple Interest = 1000  
Total Amount = 11000

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. Enter the principal amount.
2. Enter the annual rate of interest.
3. Enter the time period in years.
4. Click the Calculate button.
5. The simple interest and total amount will be displayed.
